# Lokomozio-aparatua web

Archivo principal: `index.html`.

Para publicar:
- Netlify Drop: arrastra esta carpeta o el `index.html` a https://app.netlify.com/drop
- GitHub Pages: subir `index.html` a un repo público y activar Pages desde `main` / root.
- Vercel: `vercel deploy --prod` desde esta carpeta, con sesión iniciada.
